# Value Nudge — Touch 2 (Touch Count 1)

Use when the first reconnect went unanswered. Offer something new; do not repeat the first email.

**Subject pattern:** `One idea for {{company}}`

```text
Hi {{first_name}},

Since we last spoke I put together a short idea for {{company}} around {{interest_summary_short}} — want me to send it over? If the timing has moved, tell me and I will stop nudging.{{booking_sentence}}

Best,
{{sender_name}}
```

Fill rules:

- `{{interest_summary_short}}` — a few words, not a paragraph.
- The "idea" must be something the user can actually deliver. If the user has no concrete idea, ask for one instead of inventing it.
- `{{booking_sentence}}` — ` Happy to walk you through it here: {{booking_link}}.` when a booking link exists, otherwise empty.
- Three sentences maximum. The "stop nudging" line is the opt-out; keep it.
- Never repeat the first touch's wording, and never add pressure.
