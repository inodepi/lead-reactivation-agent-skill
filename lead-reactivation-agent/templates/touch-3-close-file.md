# Close the File — Touch 3 (Touch Count 2)

Use only at the end of the sequence. This email ends the campaign; it is always queued for approval.

**Subject pattern:** `Close your file?`

```text
Hi {{first_name}},

I don't want to keep landing in your inbox, so I will close your file unless I hear back. If {{interest_summary_short}} comes back onto your roadmap, just reply and I will pick it up from there.

Best,
{{sender_name}}
```

Fill rules:

- Two sentences is enough. Do not add a pitch, a discount, or a last-chance deadline.
- `{{interest_summary_short}}` — a few words from the original interest notes.
- No booking link. This email asks for a reply, not a meeting.
- Never auto-send this template, regardless of segment or settings.
- If the user rejects it, the lead is closed — report it and stop.
